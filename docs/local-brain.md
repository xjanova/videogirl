# สมองในเครื่อง — ไฟล์โมเดลกับรันไทม์ต้องเป็นคู่เดียวกัน

## 🔴 ไฟล์ `-gpu.litertlm` ใช้กับ flutter_gemma 0.13.6 ไม่ได้

repo `litert-community/gemma-4-*-litert-lm` มีไฟล์อยู่สองตระกูล และ**หน้าตา
เหมือนกันทุกอย่างจากภายนอก** — นามสกุลเดียวกัน ขนาดใกล้กัน ชื่อต่างกันแค่ `-gpu`

อ่านหัวไฟล์จริงเมื่อ 2026-09-03 (HTTP Range 4 KB แรก):

| ไฟล์ | `backend_constraint` | ส่วนข้างใน |
|---|---|---|
| `gemma-4-E2B-it.litertlm` · `gemma-4-E4B-it.litertlm` | `cpu` | `tf_lite_prefill_decode`, `tf_lite_embedder`, `tf_lite_vision_encoder`, … |
| `gemma-4-E2B-it-gpu.litertlm` · `gemma-4-E4B-it-gpu.litertlm` | `gpu_artisan` | `gpu_artisan`, `gpu_artisan_weights_version`, `tf_lite_artisan_text_decoder` |

flutter_gemma 0.13.6 พ่วง `com.google.ai.edge.litertlm:litertlm-android:0.10.0`
ซึ่งรู้จักแต่ทางเดิน `tf_lite_prefill_decode` พอเจอไฟล์ `gpu_artisan` มันจึงตาย
ตอนสร้าง engine:

```
Failed to initialize LiteRT-LM: Failed to create engine:
NOT_FOUND: TF_LITE_PREFILL_DECODE not found in the model.
```

ไฟล์ `-gpu` ถูกสร้าง 2026-08-06 ส่วนไฟล์ CPU สร้าง 2026-04-28 — **รูปแบบใหม่กว่า
รันไทม์ที่เราพ่วงมา** ไม่ใช่ไฟล์เสียและไม่ใช่โหลดไม่ครบ

### ทำไมมันเจ็บกว่าที่ควร

พังตอน**สร้าง engine** ไม่ใช่ตอนโหลด · ลำดับที่ผู้ใช้เจอคือ

1. โหลดจบ 100% เสียเน็ต 3 GB
2. หน้าตั้งค่าขึ้นเขียว "พร้อมใช้แบบออฟไลน์"
3. ทักคำแรก → ได้ชื่อ signature ข้างในไฟล์ขึ้นมาบนจอ

ไม่มีจุดไหนก่อนหน้าที่บอกได้เลยว่าจะพัง และไม่มีเทสต์ในเครื่องไหนจับได้
เพราะไฟล์ไม่ได้อยู่ในเครื่องที่รันเทสต์ ที่ทำได้คือ**กันที่ชื่อไฟล์**
(`test/local_brain_test.dart` · "ห้ามชี้ไปที่ไฟล์ -gpu")

## แล้ว GPU ล่ะ

ต้องขยับ `flutter_gemma` ขึ้นไป — 1.7.0 (2026-08-31) ใช้ LiteRT-LM **0.16.2**
ซึ่งใหม่กว่าไฟล์ `gpu_artisan` แล้ว

แต่นั่นเป็นงานคนละก้อน: 1.7.0 ย้าย `.litertlm` ไปเดินผ่าน **Dart FFI + Native
Assets** (ฟีเจอร์ทดลองของ Flutter) และย้าย `.task` ออกไปเป็นแพ็กเกจแยก
`flutter_gemma_mediapipe` · **ยังไม่ได้ทดสอบว่าไฟล์ `gpu_artisan` ใช้ได้จริง
บนนั้น** — เป็นการอนุมานจากเลขเวอร์ชัน ไม่ใช่ของที่เห็นมากับตา

## รุ่นที่ถอดออกต้องตามไปลบไฟล์

`retiredModels` ใน [local_brain.dart](../lib/ai/local_brain.dart) มีไว้เพราะ
**ถอดชื่อออกจาก `GemmaVariant` เฉย ๆ ไม่พอ** ทั้งปุ่มลบและการสแกนตอนเปิดแอป
วิ่งบน `GemmaVariant.values` ไฟล์ 3 GB ที่ค้างอยู่จึงกลายเป็นของที่ไม่มีปุ่มไหน
ในแอปลบได้อีกเลย

ปลั๊กอินเก็บไฟล์แยกตาม**ชื่อไฟล์** (`mobile_model_manager` · `spec.files[]
.filename` ซึ่งมาจาก basename ของ URL) ไม่ใช่ชื่อรุ่น ลบตัวที่ถอดออกจึงไม่โดน
ของที่ยังใช้อยู่

|---|---|---|

ตัวเลขพวกนี้ถูกใช้ตรวจว่าโหลดครบไหม (`isComplete` เผื่อคลาดเคลื่อน 2%)

จากเน็ตที่หลุดกลางทางจึงตอบว่า "ติดตั้งแล้ว" ตลอดไปและปุ่มโหลดจะหายไป

## ค่าแนะนำเป็น E2B ทุกชั้นแรม

ตั้งแต่ไม่มีทางเดิน GPU E4B เหลือแต่ไฟล์ CPU ที่ใหญ่กว่า 1 GB และช้ากว่า
ตั้งเป็นค่าแนะนำสำหรับเครื่องแรม 12 GB เท่ากับยัดของที่ช้าที่สุดใส่มือคนที่
เครื่องแรงที่สุดโดยที่เขาไม่ได้ขอ · E4B ยังอยู่ใน `allowed` ให้เลือกเองได้
