# รับสายแทน — ทำได้แค่ไหน และติดตรงไหน

หน้านี้เป็นความจริงล่าสุดของฟีเจอร์ "เธอรับสายแทน" · ถ้าโค้ดกับหน้านี้ขัดกัน
ให้เชื่อโค้ด แล้วมาแก้หน้านี้

## สรุปสั้น

| อยากได้ | ทำได้ไหม | ทำที่ไหน |
|---|---|---|
| รู้ว่ามีสายเข้า + เบอร์ + ชื่อ | ✅ | `CallBridge.kt` · `call_watch.dart` |
| จอสายเป็นของเราเอง | ✅ | `InCallActivity.kt` (ต้องเป็นแอปโทรศัพท์หลัก) |
| รับ / ปฏิเสธ / วาง / สลับลำโพง | ✅ | `MindInCallService.kt` |
| รับสายเองอัตโนมัติหลังกริ่งดัง N วิ | ✅ | `InCallActivity.armAutoAnswer` (เฉพาะเบอร์ในสมุดโทรศัพท์) |
| **ปลายสายได้ยินเสียงเธอ** | ⚠️ ทางอ้อม | `CallAudio.kt` — ดูข้างล่าง |
| **เธอได้ยินเสียงปลายสาย** | ⚠️ ลุ้นตามเครื่อง | `call_session.dart` — ดูข้างล่าง |
| เจ้าของแทรกสายกลางทาง | ✅ | `CallSession.bargeIn` · ปุ่มบนจอสายทั้งสองจอ |
| เจ้าของพิมพ์ให้เธอพูดเข้าสาย | ✅ | `CallSession.say` — ทำงานได้ทุกเครื่อง |
| ถอดเสียงสด | ⚠️ ตามข้อ "เธอได้ยิน" | `whisper-1` ผ่าน `OpenAiClient.transcribe` |

## 🔴 เพดานที่ทุกอย่างตั้งอยู่บน

ตั้งแต่ **Android 10 (API 29)** `VOICE_CALL` / `VOICE_UPLINK` / `VOICE_DOWNLINK`
สงวนไว้ให้แอประบบและแอปของผู้ให้บริการเครือข่ายเท่านั้น
**การเป็นแอปโทรศัพท์หลักไม่ได้ให้สิทธิ์พวกนี้** และไม่มี API อื่นที่ทดแทน

ดังนั้นทั้งขาเข้าและขาออกของเสียงในสาย เราแตะไม่ได้เลย
สิ่งที่ทำอยู่ตอนนี้จึงเป็นกลไก **อะคูสติก** ไม่ใช่การต่อสายสัญญาณ

## เธอ → ปลายสาย (ทำงานได้ ถ้าเครื่องยอม)

```
TTS → ไฟล์เสียง → MediaPlayer เล่นออกลำโพง → คลื่นในอากาศ → ไมค์ของเครื่อง → ขึ้นสาย
```

ทำใน `CallAudio.kt`:
1. `InCallService.setAudioRoute(ROUTE_SPEAKER)` — บังคับเปิดลำโพง
   (ทำได้เฉพาะตอนเป็นแอปโทรศัพท์หลัก ไม่งั้น `open()` คืน false)
2. เร่งระดับเสียงของช่องที่ใช้ขึ้นสุด แล้ว **คืนค่าเดิมเมื่อสายจบเสมอ**
3. `MediaPlayer` ที่ตั้ง `USAGE_VOICE_COMMUNICATION` (หรือ `USAGE_MEDIA`)

**ตัวแปรที่ตัดสินว่าได้ยินหรือไม่ได้ยินคือ AEC ของเครื่อง**
ตัวตัดเสียงก้องมีหน้าที่ลบสิ่งที่ลำโพงเล่นออกจากสัญญาณไมค์พอดี ๆ
ซึ่งคือสิ่งที่เรากำลังทำ · บางชิปอ้างอิงเฉพาะเสียงขาลงของสาย (เสียงเธอรอด)
บางชิปอ้างอิงเสียงลำโพงทั้งหมด (เสียงเธอโดนลบ)
**อ่านจากโค้ดไม่ได้ ต้องลองกับเครื่องจริง**

จึงมีสวิตช์ **"ทางที่เสียงเธอวิ่งเข้าสาย"** ในหน้าตั้งค่า (ช่องเสียงสาย /
ช่องเสียงสื่อ) ให้เจ้าของลองสลับเมื่อปลายสายไม่ได้ยิน
ค่านี้เก็บที่คีย์ `callStream` ซึ่ง **ฝั่ง Kotlin อ่านเองด้วย** (`MindPrefs`)

## ปลายสาย → เธอ (ลุ้น)

```
เสียงคู่สายออกลำโพง → ไมค์ → AudioRecord (voiceRecognition) → VAD → whisper-1 → ข้อความ
```

หลายเครื่อง **คืนความเงียบสนิท** ให้แอปที่อัดเสียงระหว่างมีสาย
โดยไม่มี error ไม่มี permission denied — ได้ก้อนข้อมูลครบ ขนาดถูกต้อง
แต่ทุกตัวอย่างเป็นศูนย์

จับได้ทางเดียวคือ **วัดระดับเสียงที่อัดได้จริง** ซึ่งเป็นสิ่งที่
`CallSession.micLevel` ทำ และหน้าจอสายแสดงเป็นแถบเล็ก ๆ ข้างสถานะ
เงียบสนิทติดกันสามรอบ → `deaf = true` → เลิกอัด เลิกจ่ายค่าถอดเสียง
แล้วบอกเจ้าของตรง ๆ ว่าเครื่องนี้ไม่ให้ฟัง

**เมื่อหูหนวก ฟีเจอร์ยังทำงานได้ครึ่งหนึ่ง** — ช่องพิมพ์บนหน้าจอสาย
ส่งข้อความให้เธอพูดเข้าสายได้ตามปกติ เพราะทางนั้นไม่ต้องใช้ไมค์เลย

## ทางที่ไม่ต้องลุ้นเลย — รับสายฝั่งเซิร์ฟเวอร์

```
คนโทรเข้า → เบอร์ Twilio/VoIP → เซิร์ฟเวอร์เรา ↔ OpenAI Realtime
                                        ↓
                                   แอปแสดง transcript สด + แทรกสายได้
```

- **หน้าจอสายที่ทำไว้แล้วใช้ต่อได้ทั้งหมด** เปลี่ยนแค่ว่าเสียงวิ่งทางไหน
- คุณภาพเสียงดีกว่ามาก เพราะเป็นสายเสียงตรง ไม่ผ่านอากาศ
- ดีเลย์ต่ำกว่า เพราะไม่ต้องรอ TTS แล้วค่อยเล่น
- ไม่มีเรื่อง AEC ไม่มีเรื่องเครื่องไม่ให้อัด — ไม่ขึ้นกับรุ่นเครื่องเลย

ข้อแลกเปลี่ยน: มีค่าเบอร์รายเดือน + ค่านาที และต้องตั้ง forward สายจากเบอร์เดิม
ไปเบอร์ใหม่ (หรือประกาศเบอร์ใหม่ให้คนที่จะโทรหา)

## สิทธิ์ที่ต้องมี

- `READ_PHONE_STATE` + `READ_CALL_LOG` — คู่กันเสมอ ไม่งั้นเบอร์ว่างเปล่าเงียบ ๆ
- `READ_CONTACTS` — เบอร์กลายเป็นคน และเป็นตัวกรองของ auto-answer
- `ANSWER_PHONE_CALLS` — รับสาย
- `RECORD_AUDIO` — ฟังปลายสาย
- `MODIFY_AUDIO_SETTINGS` — เร่ง/คืนระดับเสียงของช่องสาย (ระบบให้ตอนติดตั้ง)
- `CALL_PHONE` — โทรออกจากแป้นของเราเอง
- บทบาท **แอปโทรศัพท์หลัก** — ผู้ใช้ต้องกดเลือกเอง ถอนได้ตลอด

🔴 เป็นแอปหลักแล้ว **ทุกสายของเครื่องผ่านแอปนี้** จอสายหรือแป้นโทรพังเมื่อไหร่
เจ้าของโทรออกรับสายไม่ได้ทั้งเครื่อง ไม่ใช่แค่ฟีเจอร์นี้เสีย

## ค่าที่ตั้งได้ในหน้าตั้งค่า

- ให้เธอรับสายอัตโนมัติ (เฉพาะเบอร์ในสมุดโทรศัพท์)
- ปล่อยให้กริ่งดังก่อนเธอรับ: ทันที / 5 / 10 / 15 / 20 / 30 / 45 / 60 วินาที
- ทางที่เสียงเธอวิ่งเข้าสาย: ช่องเสียงสาย / ช่องเสียงสื่อ
- เสียงของช่อง "เสียงตอบรับ" แยกจากเสียงที่คุยในแอป

## ยังไม่ได้ทำ

- สรุปสายให้เจ้าของฟังหลังวาง (ตอนนี้บทสนทนาอยู่บนหน้าจอสายอย่างเดียว
  แล้วหายไปเมื่อสายถัดไปเริ่ม)
- เก็บบทสนทนาในสายเข้าความจำระยะยาว (`MindMemory`)
- คัดกรองสายแปลกด้วย `CallScreeningService`
- โทรออกแทนเจ้าของ (มีเสียง `VoiceChannel.outgoing` เตรียมไว้แล้ว แต่ยังไม่มีคนเรียก)
