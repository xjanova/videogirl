# รับสายแทน — ข้อจำกัดจริงของ Android

หน้าจอ 1b/2b (สายเข้า) กับ 1c/2c (โทรออก) ใน artboard ออกแบบไว้แล้ว
แต่ **ยังทำไม่ได้ตามที่ออกแบบบน Android ปกติ** จึงพักไว้ก่อน

## สิ่งที่ทำได้ กับทำไม่ได้

| อยากได้ | ทำได้ไหม | หมายเหตุ |
|---|---|---|
| รู้ว่ามีสายเข้า + เบอร์อะไร | ✅ | `CallScreeningService` (API 24+) |
| คัดกรอง/ปฏิเสธสายแปลก | ✅ | `CallScreeningService` |
| กดรับสายอัตโนมัติ | ✅ | `TelecomManager.acceptRingingCall()` + `ANSWER_PHONE_CALLS` (API 26+) |
| หน่วงเวลาก่อนรับ | ✅ | ตั้งได้ในหน้าตั้งค่าแล้ว (0–60 วินาที) |
| **ได้ยินเสียงคู่สาย** | ❌ | **ตัวบล็อกหลัก** |
| **ให้เธอพูดเข้าไปในสาย** | ❌ | ตามข้างบน |
| ถอดเสียงสด | ❌ | ต้องได้ยินก่อนถึงจะถอดได้ |

## ทำไมได้ยินไม่ได้

ตั้งแต่ **Android 10 (API 29)** Google ปิด audio source `VOICE_CALL`,
`VOICE_DOWNLINK` และ `VOICE_UPLINK` ไว้ให้เฉพาะแอประบบและแอปของผู้ให้บริการเครือข่าย
แอปทั่วไปที่ลง Play Store เข้าไม่ถึงเลย ต่อให้ผู้ใช้กดอนุญาตทุกอย่างก็ตาม

การอัดจากไมค์ตอนเปิดลำโพงก็ไม่ใช่ทางออก — คุณภาพแย่ ได้เสียงห้องปนมาหมด
และหลายประเทศ (รวมไทย) มีข้อกฎหมายเรื่องการบันทึกการสนทนา

การใช้ `AccessibilityService` อ้อมไปทางอื่นก็ผิดนโยบาย Play Store
(นโยบายกำหนดว่า accessibility API ต้องใช้เพื่อช่วยผู้พิการเท่านั้น) — โดนถอดแอปได้

## ทางที่ทำได้จริง

### ทางที่แนะนำ — ให้ AI รับสายฝั่งเซิร์ฟเวอร์

```
คนโทรเข้า → เบอร์ Twilio/VoIP → เซิร์ฟเวอร์เรา ↔ OpenAI Realtime
                                        ↓
                                   แอปแสดง transcript สด + แทรกสายได้
```

- UI ที่ออกแบบไว้ **ใช้ได้เหมือนเดิมทุกพิกเซล** เปลี่ยนแค่เสียงวิ่งทางไหน
- `gpt-realtime-2.1` ทำ speech-to-speech ได้โดยตรง ดีเลย์ต่ำพอสำหรับคุยโทรศัพท์
- คุณภาพเสียงดีกว่าอัดจากไมค์มาก เพราะเป็นสายเสียงตรง
- มีค่าเบอร์รายเดือน + ค่านาที

ข้อแลกเปลี่ยน: ต้องประกาศเบอร์ใหม่ให้คนที่จะโทรหา หรือตั้ง forward สายจากเบอร์เดิม

### ทางที่ทำได้เลยโดยไม่ต้องมีเซิร์ฟเวอร์

รับสายอัตโนมัติ + คัดกรองสายกวน + อ่านชื่อคนโทรเข้าให้ฟัง — แต่**ไม่มี transcript**
เธอรับได้ แต่ไม่ได้ยินว่าปลายสายพูดอะไร ซึ่งทำให้ครึ่งหนึ่งของคุณค่าหายไป

## ค่าที่ตั้งไว้แล้วในแอป

หน้าตั้งค่ามีส่วน **"รับสายแทน"** พร้อมใช้งานแล้ว:
- สวิตช์เปิด/ปิดรับสายอัตโนมัติ
- เลือกเวลาที่ปล่อยให้กริ่งดังก่อนเธอรับ: ทันที / 5 / 10 / 15 / 20 / 30 / 45 / 60 วินาที
  (ค่าเริ่มต้น 15 วินาที เผื่อให้เจ้าของคว้าเครื่องก่อน)

ค่าพวกนี้บันทึกลงเครื่องแล้ว รอแค่ชั้น telephony มาต่อ

## สิทธิ์ที่จะต้องขอเพิ่มเมื่อทำจริง

จาก artboard 2h เขียนกำกับไว้แล้ว:

- `ANSWER_PHONE_CALLS` — รับสาย
- `READ_PHONE_STATE` / `READ_CALL_LOG` — รู้สถานะและเบอร์
- `ROLE_CALL_SCREENING` — คัดกรอง (ผู้ใช้ต้องกดเลือกให้แอปนี้)
- `FOREGROUND_SERVICE` + แจ้งเตือนถาวร — ทำงานเบื้องหลัง
- `SYSTEM_ALERT_WINDOW` — ฟองลอยบนหน้าจออื่น
- ต้องให้ผู้ใช้ปิด battery optimization ให้แอปนี้ ไม่งั้นระบบจะฆ่าทิ้งตอนหน้าจอดับ
