# ทำชุดให้มายด์ (avatar pack)

ชุด = ไฟล์ `.zip` หนึ่งไฟล์ที่แอปโหลดมาแตกลงเครื่อง มีได้หลายชุดพร้อมกัน สลับได้ในหน้าตั้งค่า

## โครงในไฟล์ zip

**ไฟล์วางแบน ๆ ไม่ต้องมีโฟลเดอร์ครอบ** (ถ้ามีครอบชั้นเดียวแอปถอดให้เอง —
คนบีบไฟล์ด้วยคลิกขวาบน Windows จะได้โฟลเดอร์ครอบเสมอ)

```
pack.json          ← รายละเอียดชุด (ไม่มีก็ได้ แต่ควรมี)
nana.vrm           ← โมเดล
clips.json         ← รายชื่อคลิป (เฉพาะชุดที่มีคลิปมาด้วย)
Idle.fbx  Wave.fbx …
```

## pack.json

```json
{
  "id": "nana-office",
  "name": { "th": "นานา ชุดออฟฟิศ", "en": "Nana — office outfit" },
  "kind": "character",
  "model": "nana.vrm",
  "providesClips": true
}
```

| ช่อง | ต้องมีไหม | ความหมาย |
|---|---|---|
| `id` | ควรมี | รหัสชุด กลายเป็นชื่อโฟลเดอร์ · **a-z 0-9 . _ -** เท่านั้น ยาวไม่เกิน 48 · ไม่ใส่ = ตั้งจากชื่อไฟล์ .vrm |
| `name.th` / `name.en` | ควรมี | ชื่อที่โชว์ในหน้าตั้งค่า · ไม่ใส่ = ใช้ `id` |
| `kind` | ไม่ | `character` (ค่าตั้งต้น) หรือ `outfit` |
| `model` | ไม่ | ชื่อไฟล์ .vrm · **ไม่ใส่หรือใส่ผิด แอปหา .vrm ตัวแรกให้เอง** |
| `providesClips` | ไม่ | ชุดนี้แบ่งคลิปให้ชุดอื่นยืมไหม · ไม่ใส่ = ดูจากว่ามี `clips.json` ไหม |

ทุกช่องพลาดได้หมดโดยชุดยังใช้งานได้ ตราบใดที่**มีไฟล์ `.vrm` อย่างน้อยหนึ่งไฟล์**
เจตนาคือชุดที่แพ็กมาไม่เนี้ยบต้องไม่ถูกปฏิเสธด้วยเหตุผลที่คนทำแก้เองไม่ถูก

## 🔴 คลิปท่าทางใช้ร่วมกัน — ชุดเสื้อผ้าไม่ต้องแบกคลิปมา

คลิป 20 กว่าไฟล์หนักกว่าตัวโมเดลรวมกันอีก ถ้าทุกชุดแบกมาเอง
ซื้อชุดที่สองก็เท่ากับโหลดของเดิมซ้ำทั้งกอง

ชุดแรกที่ตั้ง `providesClips: true` จะถูกก๊อปคลิปขึ้น**กองกลาง**
ชุดที่โหลดทีหลังมีแค่ `.vrm` กับ `pack.json` ก็พอ — เวลาเล่น แอปหาไฟล์ใน
**ชุดที่ใส่อยู่ก่อน แล้วค่อยตกไปกองกลาง**

ลำดับนี้สำคัญ: ชุดที่มีคลิปของตัวเองจะได้ใช้ของตัวเอง ไม่ใช่ของกองกลาง
ที่อาจเป็นของตัวละครอื่นซึ่งสัดส่วนกระดูกไม่เหมือนกัน

## ทำไฟล์

```bash
cd <โฟลเดอร์ชุด> && zip -r ../nana-office.zip . && cd -
```

ปลายทางจริงคือ **ร้านใน xman studio** ที่แอดมินเพิ่มชุดและตั้งราคาได้เอง
ดูสัญญา API ที่ [pack-store.md](pack-store.md)

ระหว่างที่ร้านยังไม่เสร็จ วางไฟล์ที่ HTTPS ที่เปิดอ่านได้ แล้ววาง URL
ในหน้าตั้งค่า → **ชุดตัวมายด์** → เพิ่มชุดใหม่ (ช่องนี้จะยังอยู่ต่อไป
สำหรับทดสอบชุดที่ยังไม่ขึ้นร้าน)

## ข้อควรรู้เรื่องความปลอดภัย

`id` มาจากไฟล์ที่โหลดจากอินเทอร์เน็ต และกลายเป็นชื่อโฟลเดอร์จริง
แอปจึงล้างมันก่อนเสมอ (`../` เดินออกนอกรากไม่ได้ · ไฟล์ซ่อนไม่ได้)
มีเทสต์ล็อกไว้ใน `test/avatar_pack_test.dart`

ชุดถูกแตกลง**ที่พักก่อน** แล้วค่อยย้ายเข้าที่จริงเมื่อรู้ว่ามี `.vrm` จริง
ชุดที่แพ็กผิดจึงทำลายชุดเดิมที่ใส่อยู่ไม่ได้

## clips.json — คลิปท่าทาง

หนึ่งบรรทัดต่อหนึ่งคลิป · ไฟล์ที่ระบุไว้แต่ไม่มีจริงจะถูกข้ามพร้อมโน้ตในล็อก
ไฟล์นี้จึงเขียนเผื่ออนาคตได้โดยไม่พัง

```json
{ "id": "dance", "file": "Silly Dancing.fbx", "role": "gesture",
  "mood": ["happy", "neutral"], "weight": 0.2 }
```

| ช่อง | ความหมาย |
|---|---|
| `role` | `idle` วนตลอด · `gesture` เล่นทับแล้วคืนร่าง · `pose` ค้างจนสั่งเลิก · `transition` เข้า/ออกจาก pose |
| `mood` | ใช้กับอารมณ์ไหนได้บ้าง · **ว่าง = ได้ทุกอารมณ์** |
| `weight` | ตัวสุ่มยามว่างหยิบท่านี้บ่อยแค่ไหน เทียบกับท่าอื่นในคลังเดียวกัน · ไม่ใส่ = 1 |

### 🔴 `mood: ["speaking"]` คือคลังคนละใบ

`speaking` **ไม่ใช่อารมณ์จริง** ไม่มีอะไรในแอปตั้งค่านี้ การใส่ลงไปมีผลสองอย่าง
พร้อมกัน: คลิปนั้น**หลุดจากคลังยามว่าง** และ**เข้าไปอยู่ในคลังที่เล่นตอนเธอพูด**

คลิปที่มือขยับเหมือนกำลังพูดกลางประโยค (Talking, Agreeing) ต้องอยู่ตรงนี้
ไม่ใช่ในคลังยามว่าง — ไม่งั้นเธอจะโบกมืออธิบายอะไรสักอย่างตอนที่**ไม่มีใครพูด**
ซึ่งเป็นสิ่งที่เกิดขึ้นจริงมาก่อนหน้านี้ และดูเหมือนขยับแขนมั่ว ๆ

### เลือก `weight` ยังไง

ท่าที่ดูเป็นธรรมชาติเมื่อเห็นบ่อย (มองไปรอบ ๆ พยักหน้า) ให้ 1
ท่าที่ดูตลกครั้งแรกแต่ดูปลอมครั้งที่สาม (เต้น หาว โบกมือ) ให้ 0.2–0.4
คลังยามว่างตอนอารมณ์ปกติมีท่าให้เลือกไม่กี่ท่า ทุกน้ำหนักจึงมีผลจริง
