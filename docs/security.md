# ความปลอดภัย

## คีย์ OpenAI ที่ฝังใน APK — ใช้ได้เฉพาะช่วงทดลอง

ตอนนี้คีย์ถูกส่งเข้าแอปตอน build ผ่าน `--dart-define` ซึ่ง **ฝังคีย์ลงในไบนารี**

`String.fromEnvironment` ไม่ได้เข้ารหัสอะไรเลย มันแค่แทนค่าคงที่ลงในโค้ดตอนคอมไพล์
ใครก็ตามที่โหลด APK จาก GitHub Releases (ซึ่ง repo นี้เป็น public) แล้วรัน

```bash
unzip -p app-release.apk assets/flutter_assets/... | strings | grep 'sk-'
```

ก็อ่านคีย์ได้ทันที ไม่ต้องแกะอะไรซับซ้อน `--obfuscate` ก็ไม่ช่วย เพราะมันย่อชื่อ
สัญลักษณ์ ไม่ได้ซ่อนค่าคงที่ที่เป็นสตริง

### แปลว่าอะไร

- **ระหว่างทดลองเอง** — ยอมรับได้ แต่ต้องรู้ว่าคีย์เท่ากับเปิดเผยแล้ว
- **ก่อนให้คนอื่นใช้** — ต้องย้ายออกจากแอปก่อน ไม่มีทางลัด

### ทางที่ถูกต้อง

ให้แอปคุยกับ backend ของเราเอง แล้ว backend ถือคีย์ OpenAI ไว้ฝั่งเซิร์ฟเวอร์:

```
แอป --(token ของผู้ใช้)--> backend เรา --(คีย์ OpenAI)--> OpenAI
```

ได้เพิ่มอีกสามอย่างที่แอปเดี่ยว ๆ ทำไม่ได้:
- **จำกัดโควตาต่อผู้ใช้** — คีย์หลุดหนึ่งเครื่องไม่ทำให้บิลทั้งบัญชีพัง
- **เพิกถอนได้ทีละคน** — ไม่ต้องออก APK ใหม่ทั้งชุด
- **เปลี่ยนโมเดล/prompt ได้โดยไม่ต้องอัปเดตแอป**

pattern นี้เคยทำแล้วใน `aixman` (`resolveUserId()` รับได้ทั้ง Bearer และ cookie)
ไม่ต้องเขียน endpoint ชุดใหม่ทั้งหมด

## คีย์ที่ใช้อยู่ตอนนี้

คีย์ที่ใช้ทดลองในเครื่อง **ผ่านช่องแชทมาแล้ว** จึงต้องถือว่าเปิดเผย
เมื่อเลิกทดลองให้ **revoke ที่ platform.openai.com** ไม่ใช่แค่ลบไฟล์ทิ้ง

## สิ่งที่ห้ามขึ้น git (บังคับผ่าน .gitignore แล้ว)

| ของ | ทำไม |
|---|---|
| `*.env` `secrets.json` | มีคีย์ |
| `android/key.properties` `*.jks` | คีย์เซ็นแอป หลุดแล้วมีคนปลอม APK อัปเดตทับได้ |
| `assets/avatar/model/` | คลิป Mixamo ห้ามแจกต่อ + โมเดล VRM |
| `android/local.properties` | path เฉพาะเครื่อง |

## ที่จัดการไปแล้วในโค้ด

- **cleartext เปิดเฉพาะ localhost** ไม่ได้เปิดทั้งแอป
  ([network_security_config.xml](../android/app/src/main/res/xml/network_security_config.xml))
  ถ้าเปิดทั้งแอปเพื่อความสะดวก ทุก endpoint จะโดนดักกลางทางได้
- **ตรวจ SHA-256 ก่อนติดตั้งอัปเดตเสมอ** ไม่มีแฮช = ไม่ติดตั้ง
  ([updater.dart](../lib/update/updater.dart))
- **ข้อความ error ไม่พ่นของดิบให้ผู้ใช้** — ไม่มี URL ไม่มี header ไม่มี stack trace
  ([openai_client.dart](../lib/ai/openai_client.dart))
- **escape ก่อนยัดค่าเข้า JS** และส่ง base64 ผ่าน `arguments` ไม่ใช่ต่อสตริง
  ([avatar_view.dart](../lib/avatar/avatar_view.dart))
- **ขอบเขตการตอบเขียนแบบ default-deny** — ไม่ได้อนุญาตชัดเจน = ถามเจ้าของก่อน
  ([minde_persona.dart](../lib/ai/mind_persona.dart))
- **เสียงจากไมค์ไปที่เดียวกับที่ข้อความไป** ไม่ใช่ที่ที่บังเอิญมีคีย์
  ([mind_state.dart](../lib/state/mind_state.dart) · `_networkBrain`)

  คนที่เลือก "สมองในเครื่อง" เลือกเพราะไม่อยากให้อะไรออกนอกเครื่อง
  การส่งเสียงเขาไปถอดที่ OpenAI เพราะ "เขากรอกคีย์ไว้อยู่แล้ว" คือการผิด
  สัญญาข้อเดียวที่ทางนั้นให้ไว้ — และเสียงพูดอ่อนไหวกว่าข้อความที่พิมพ์อีก
  จึงปิดไมค์ไปเลยพร้อมบอกเหตุผล ดีกว่าให้มันทำงานโดยแอบเปลี่ยนปลายทาง

## สำเนาข้อมูลที่อยู่นอกพื้นที่แอป

ข้อมูลทั้งหมด (ค่าตั้งค่า บทสนทนา ความจำ ไทม์ไลน์) อยู่ใน SQLite ที่
`getApplicationSupportDirectory()` แล้วส่งสำเนาไปไว้ที่
`/storage/emulated/0/GigGok/mind.db` เพื่อให้ **รอดจากการถอนแอป**
(ทุกอย่างใน `/data/data/<pkg>/` ถูกล้างตอน uninstall รวม `Android/data/<pkg>/`)

🔴 **ไฟล์สำเนาอยู่ในพื้นที่เก็บร่วม แอปอื่นที่มีสิทธิ์อ่านไฟล์เปิดดูได้**
สิ่งที่ตามมาและตัดสินใจไว้แล้ว:

| ของ | อยู่ไหน | เหตุผล |
|---|---|---|
| คีย์ OpenAI ของผู้ใช้ | **Keystore เท่านั้น** | เสียเงินจริงและไม่จำกัด · ห้ามลง SQLite ไม่ว่ากรณีใด |
| รหัสสิทธิ์ (license) | ในฐาน = อยู่ในสำเนา | เจ้าของต้องการให้กลับมาเองตอนลงใหม่ · หลุดไปทำได้แค่กินโควตาของไลเซนส์นั้น ซึ่งหลังบ้านจำกัดอยู่แล้ว |
| บทสนทนา / ความจำ | ในฐาน = อยู่ในสำเนา | เป็นสิ่งที่ต้องรอด · อยู่บนเครื่องของเจ้าของเอง |

ผู้ใช้ปิดได้ด้วยสวิตช์ **"ลบข้อมูลทั้งหมดเมื่อถอนแอป"** ในหน้าตั้งค่า
ซึ่ง **ลบสำเนาทิ้งทันทีที่ติ๊ก** ไม่ใช่รอถึงวันถอนแอป — เพราะวันนั้นไม่มีโค้ด
ของเราวิ่งอยู่เลยที่จะไปลบให้ได้ (Android ไม่มี hook ตอน uninstall ที่เชื่อถือได้)
ทางเดียวที่คำสัญญานี้เป็นจริงคือไม่ทิ้งอะไรไว้ข้างนอกตั้งแต่แรก

## ที่ยังไม่ได้ทำ

- ยังไม่มี certificate pinning กับ `api.openai.com`
- สวิตช์ในหน้าตั้งค่าที่ต้องขอสิทธิ์ Android ยังไม่ผูกกับสถานะสิทธิ์จริง
  (เปิดสวิตช์ไว้แต่ระบบไม่ให้ = แอปโกหกผู้ใช้)
- ยังไม่มีการจำกัดจำนวนครั้งที่เรียก OpenAI ต่อวัน
