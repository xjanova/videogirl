# เสียงพรีเมียม — Gemini · ElevenLabs · Azure (ตรวจ 2026-10-06)

ผู้ใช้ใส่คีย์ของตัวเอง เก็บใน `SecretStore` (Keystore) ของเครื่องเท่านั้น ·
โค้ด: `lib/ai/premium_tts.dart` (เรียก API) · `lib/ai/premium_catalog.dart` (รุ่น/เสียง)
· เจ้าของสั่งว่า **"ที่คุณภาพดี ๆ เท่านั้น"** — รายการจึงมีแต่รุ่นคุณภาพสูงที่พูดไทยได้

| เจ้า | รุ่นในรายการ | เสียง | คุมน้ำเสียง |
|---|---|---|---|
| Google Gemini | `gemini-3.8-flash-tts` (GA 22 ก.ย. 2026) | สำเร็จรูป 8 เสียง (Sulafat ตั้งต้น) | `speech_metadata.style` — **ห้ามปนในข้อความ** รุ่นนี้อ่านทุกตัวอักษรออกเสียง |
| ElevenLabs | `eleven_v4` (ผ่าน `/v1/text-to-dialogue`) · `eleven_v3` | โหลดจากบัญชีผู้ใช้ (`GET /v2/voices`) | แท็กในข้อความ เช่น `[whispers]` |
| Azure | — (เลือกที่เสียง) | Premwadee · Achara · Niwat (ไทย GA) · Ava/Emma Multilingual (อังกฤษ) · โหลดเพิ่มจากภูมิภาคได้ | ไม่มี (เสียงไทย GA ไม่มี style) |

Flash v2.5 · Azure DragonHD (ไม่มี th-TH)

## กับดักที่ต้องรู้

- **Gemini** ตอบเป็น JSON base64 · รุ่นใหม่ได้ WAV ที่มีหัวแล้ว รุ่นเก่าได้ PCM ดิบ
  24 kHz → `geminiAudio` รับทั้งสองแบบ · แผนฟรีของ Google เอาข้อมูลไปปรับปรุงบริการ ·
  ราคาจะขึ้นสองเท่า 1 ม.ค. 2027
- **ElevenLabs** ต้องส่ง `model_id` เสมอ ไม่ส่ง = multilingual_v2 ที่ไม่มีไทย ·
  **ห้ามฝัง voice ID** — เสียง default หมดอายุ 31 ธ.ค. 2026 · ยังยืนยันไม่ได้ว่า v4 ใช้กับ
  `/v1/text-to-speech` ได้ จึงส่งทาง text-to-dialogue ตามเอกสาร
- **Azure** ปลายทางผูกกับภูมิภาค · ข้อความต้อง escape ก่อนใส่ SSML · เสียง MAI-Voice-2.1
  ยังเป็น preview และชื่อในเอกสารขัดกันเอง จึงไม่ฝังไว้ (โหลดจากภูมิภาคเอาได้)
- ทุกเจ้าล้ม → ตกไปเสียงเครื่อง **และบอกเหตุผลใต้ช่องพิมพ์** (คีย์ผิด / เครดิตหมด)

## การเช่าเสียงผ่านบริการของเรา — ปิดไว้

เจ้าของกำหนดว่าการเช่าต้องต่อผ่านหลังบ้าน **aixman** (ai.xman4289.com) และถ้ายังไม่มีให้
ปิดไว้ · ตรวจแล้ว (2026-10-06) aixman **ยังไม่มีระบบเสียงพูดเลย** และไม่มีการเช่าแบบรายเวลา
(มีแค่เครดิตแบบจ่ายตามใช้) จึงยังไม่มีปุ่มเช่าในแอป

สิ่งที่ aixman ต้องมีก่อนเปิด:
1. เมธอดเสียงพูดใน adapter + ตัวต่อ ElevenLabs / Gemini / Azure ในพูลคีย์
2. ทาง `audio` สำหรับผู้ให้บริการ API ใน `generation.ts` และ MIME เสียงในที่เก็บ R2
3. คิดราคาตามจำนวนตัวอักษร (ตอนนี้คิดเหมาต่อครั้ง)
4. ให้แอปยืนยันตัวได้ — aixman รับแค่บัญชีผู้ใช้ (Bearer จาก SSO/รหัสผ่าน) ไม่รับไลเซนส์ของแอป
5. ถ้า "เช่า" ต้องเป็นรายเวลา: ตาราง entitlement ใหม่
