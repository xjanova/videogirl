# สตูดิโอ — เธอในวิดีโอคอล ไลฟ์ และคลิป

หน้านี้เป็นความจริงล่าสุดของโหมดสตูดิโอ · ถ้าโค้ดกับหน้านี้ขัดกัน ให้เชื่อโค้ด

## 🔴 ทำไมไม่เป็น "กล้องเสมือน"

Android ไม่มี API ให้แอปทั่วไปประกาศตัวเป็นกล้อง (ต้อง root หรือเป็นแอประบบ)
แอปวิดีโอคอลจึงเลือกเธอเป็นกล้องไม่ได้ · ทางที่ใช้ได้กับทุกแอปคือ **แชร์หน้าจอ**
สตูดิโอจึงทำให้ทั้งจอเป็นเธอล้วน ๆ แล้วให้แอปวิดีโอคอลแชร์จอนั้น

## มีอะไรบ้าง

| ใช้ทำอะไร | ทำยังไง | ที่อยู่ในโค้ด |
|---|---|---|
| วิดีโอคอล | เวทีเต็มจอ ไม่มีปุ่ม (ปุ่มหายเองใน 4 วิ แตะจอเพื่อเรียก) · ซ่อนแถบระบบ · จอไม่ดับ | `MindStudio.enter` · `StudioOverlay` |
| จอลอย | ปุ่ม "จอลอย" หรือกด Home ตอนอยู่ในสตูดิโอ (Android 12+ ระบบทำเอง, 8–11 ผ่าน `onUserLeaveHint`) | `MindStudio.kt` |
| ไลฟ์ / OBS | ฉากหลังสีทึบ เขียว `#00b140` ฟ้า `#0047bb` บานเย็น ดำ ขาว หรือรหัสสีเอง · วาดใน WebGL (`scene.background`) จึงตรงรหัสสีเป๊ะ | `avatar.js setBackdrop` |
| อัดคลิป | อ่านจากผืนผ้าใบของเวทีตรง ๆ (`captureStream`) + เสียงเธอจากท่อ WebAudio + ไมค์ถ้าเปิด → `MediaRecorder` → ก้อนละวินาทีข้ามสะพาน → `Movies/GigGok` | `recorder.js` · `MindStudio` |
| หน้าเธอตามหน้าเรา | กล้องเชิดหุ่นเดิม (`mocap.js`) · ตอนเธอพูดอยู่ ปากเป็นของเสียง สีหน้า/หัว/สายตายังเป็นของกล้อง | `avatar.js _face` |

ระยะภาพ (หน้า/ครึ่งตัว/เต็มตัว) **ล็อกตลอด** ในสตูดิโอ ไม่ว่าจะเชิดอยู่หรือไม่ —
กล้องที่ดึงเข้าออกเองตอนพูดคือภาพที่กระชากในสายของคนอื่น

## ข้อจำกัดที่รู้แล้ว

- แอปวิดีโอคอลที่**เปิดกล้องอยู่จะแย่งกล้องหน้า** กับโหมดตามหน้า · ให้ปิดกล้องในแอปนั้น แล้วใช้แชร์หน้าจอแทน
- อัดคลิปตอนแอป**พับลง** (ไม่ใช่จอลอย) ไม่ได้ เวทีหยุดวาด → สตูดิโอหยุดอัดแล้วบันทึกส่วนที่ได้ให้เอง
- ฉาก "พื้นแอป" โปร่งบนจอ แต่ตอนอัดวาดสีไล่ของแอปลงไปแทน (ตัวเข้ารหัสทิ้ง alpha = พื้นดำ)
- ชนิดไฟล์ขึ้นกับ WebView ของเครื่อง: mp4 ถ้ารองรับ ไม่งั้น webm (แกลเลอรีส่วนใหญ่เล่นได้ทั้งคู่)
- อัดได้ครั้งละไม่เกิน 30 นาที
- ⚠️ **ยังไม่ได้ลองบนเครื่องจริง** ทั้งจอลอย การอัด และการบันทึกลงแกลเลอรี

## ปากของเธอตอนรับสาย

ตอนอยู่ในสาย เสียงเธอออกทางเนทีฟ (ช่องเสียงสาย) ห้ามดังจากเวทีซ้ำ · ของเดิมปาก
จึง "พึมพำ" แบบสุ่ม**ทั้งสาย** รวมทั้งตอนคู่สายพูด · ตอนนี้เวทีเล่นไฟล์เดียวกัน
แบบปิดเสียง (gain 0) แล้วอ่านคลื่นไปขยับปาก (`MindLips` · `LipSync.prepare/go`)
หน่วงไว้ `CallSession.lipLead` = 60ms ให้ตรงกับเสียงที่ออกลำโพงจริง (ค่าประมาณ ยังไม่ได้วัด)

ตอนคุยปกติในแอป ปากก็หน่วงตาม `AudioContext.outputLatency` ที่เบราว์เซอร์รายงาน
— ลำโพง Bluetooth หน่วงเป็นร้อยมิลลิวินาที ไม่หน่วงตามแล้วปากจะนำเสียงจนดูเป็นพากย์
