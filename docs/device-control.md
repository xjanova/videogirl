## โปรเซส

Android ปิด `/proc` และ `getRunningAppProcesses` ให้แอปเห็นแค่ตัวเอง · ทางเดียวคือ `ps -A` ในฐานะ shell ผ่าน
`DirectAudioServer` (argv ตายตัว ไม่ผ่าน shell ไม่รับอาร์กิวเมนต์ · ชื่อโปรเซสตัดเหลือ ASCII พิมพ์ได้ · เฟรมเดียว)

- 🔴 `AudioProtocol.VERSION` ห้ามขยับ · ตัวช่วยรุ่นเก่าจะปฏิเสธการเชื่อมต่อแล้วเสียงสายพังทั้งชุด · คำสั่งใหม่ที่รุ่นเก่าไม่รู้จักตอบ `error:` เฉย ๆ (`old_helper`)
- 🔴 หลังลงแอปรุ่นนี้ ตัวช่วยที่รันอยู่ยังเป็นตัวเก่า ต้องเชื่อมใหม่หนึ่งครั้งที่ ตั้งค่า › รับสาย
- ระหว่างสายใช้ไม่ได้: ตัวช่วยมีได้เซสชันเดียว และเซสชันนั้นคือสาย (`in_call`)
- ดูอย่างเดียว ไม่มีคำสั่งปิดโปรเซส (ทำลายงานเจ้าของได้ และไม่มีใครขอ)
- ห้ามสลับ Wireless debugging เพื่ออ่านรายการนี้ · บาง ROM ฆ่าตัวช่วย

## ตารางแอป (`lib/hands/app_table.dart` · ตาราง `apps` รุ่นฐาน 4)

- แอปหลังบ้านรับข่าวติดตั้ง/ถอนไม่ได้ · เทียบรายการในเครื่องตอนเปิดแอป กลับเข้าแอป ทุกสิบนาทีระหว่างคุย และตอนเปิดแอปไม่เจอ
- 🔴 รายการว่างหรืออ่านไม่ได้ = ไม่เปลี่ยนอะไร · ไม่กันคือถอดทุกแอป หมวดและชื่อเรียกหายทั้งตาราง
- ตารางเปล่าครั้งแรกไม่นับเป็นข่าว · ถอดแล้วลงใหม่ หมวดและชื่อเรียกยังอยู่ · หมวดที่ตั้งเอง (`own_category`) การเดาใหม่ทับไม่ได้
- `find`: ตรงเป๊ะ > ขึ้นต้น > มีคำนั้น · เท่ากันทุกแถว = null ให้ตัวหาฝั่ง Android ตอบพร้อมตัวเลือก แทนการเปิดผิดแอป
- 🔴 ชื่อแอปคือข้อความจากคนอื่น · ทุกทางเข้าโมเดลผ่าน `_one` ไม่ให้เหลือรูป `[[…]]`
- ข่าวใน prompt ไม่มีคำบอกเวลาสัมพัทธ์ · prompt ที่เปลี่ยนทุกตาบังคับสมองในเครื่องเริ่ม session ใหม่

## จัดไอคอน

Android ไม่มี API ให้แอปอื่นย้ายไอคอนของตัวเปิดแอป · ทางเดียวคือนิ้วจำลอง: กดค้าง 750 ms แล้วลากต่อด้วย `continueStroke`
ทั้งเส้นเป็นนิ้วเดียว · ค้างปลายทาง 450 ms (ขอบจอ 1200 ms ให้พลิกหน้า) · ลงบนไอคอนอื่น = ทำโฟลเดอร์

- ตารางแอปไม่ได้ย้ายไอคอน · ตารางคือความรู้ของเธอ การย้ายจริงคือ `phone_task`
- `PhonePolicy`: ลงบนปุ่มที่มีคำเสี่ยง (ถอนการติดตั้ง ลบ) ต้องถามเจ้าของ · ตัวติดตั้งแอปเป็นด่านระบบที่มือแตะไม่ได้อยู่แล้ว
- งานหนึ่งมีสูงสุด 30 ขั้น จึงแบ่งเป็นรอบ

## เซ็นเซอร์และสุขภาพ

อ่านอย่างเดียวผ่าน `PhoneLookup` ชนิด `sensors` และ `health` ทั้งแท็กในแชทและเครื่องมือ `phone_lookup` ตอนคุยสด ·
อ่านครั้งเดียวตอนเจ้าของถาม ไม่มีการเฝ้าค้างและไม่มีประวัติในแอป

- 🔴 สุขภาพอ่านทีละเรื่องตามชื่อที่เอ่ย · ไม่เอ่ยชื่อ = ไม่อ่านอะไร ไม่มีคำว่า "ทั้งหมด" · สมองบนคลาวด์เห็นเฉพาะตัวเลขของคำถามนั้น ·
  ผลไม่ลงบทสนทนา แต่คำตอบของเธอลง จึงอาจไปถึงสำเนาในที่เก็บร่วมเหมือนเรื่อง SMS
- 🔴 ด่านอยู่ที่ `PhoneLookup.healthBarred` (`_healthBarred`) ไม่ใช่ `barred` · แน่นกว่า `_voiceBarred`: เครื่องล็อก = ไม่อ่านทุกทาง
  ไม่ใช่แค่ตอนเรียกด้วยเสียง · มีสายอยู่ = ไม่อ่าน · ถามสถานะล็อกไม่ได้ = ถือว่าล็อก · ไม่ได้ต่อด่าน = อ่านไม่ได้
- 🔴 ในสายไม่มีทางถึง: persona ไม่สอนแท็กเมื่อ `onCall` · เครื่องมือของสาย (`voice_session.dart`) ไม่มี `phone_lookup`
- ก้าวและชีพจรถามผ่าน `[[เซ็นเซอร์: ก้าว]]` ก็ถูกส่งเข้าด่านเดียวกัน · `[[เซ็นเซอร์]]` เว้นว่างบอกแค่ว่ามีตัวนับก้าว ไม่อ่านค่า
- สิทธิ์ `onDemand` ไม่อยู่ในปุ่มขอทีเดียว และไม่นับเป็น "ยังขาด" · เจ้าของที่ไม่เคยถามจะไม่เห็นกล่องขอ
- ปฏิเสธ Health Connect แล้วไม่เด้งกล่องตัวนับก้าวซ้ำ · ตอบจากตัวนับเฉพาะเมื่อให้สิทธิ์ไว้ก่อนแล้ว

กับดักที่ไม่มี error ให้เห็น:

- 🔴 ไม่มีสิทธิ์ ≠ ไม่มีเซ็นเซอร์ · Android 10 ขึ้นไปซ่อนตัวนับก้าวและตัววัดชีพจรจาก `getDefaultSensor` เมื่อขาดสิทธิ์ ·
  ตัวนับก้าวจึงดูสิทธิ์ก่อน ตัววัดชีพจรดู `FEATURE_SENSOR_HEART_RATE` ก่อน (ไม่ขอสิทธิ์ใส่เครื่องที่ไม่มี)
- 🔴 ไม่มี `HealthRationaleActivity` (ทั้ง rationale และ alias `VIEW_PERMISSION_USAGE`) กล่องขอสิทธิ์ไม่ขึ้นเลย และตอบกลับเหมือนกดปฏิเสธ
- 🔴 แอปตั้งเป้า API 36 · Android 16 ขึ้นไปใช้ `READ_HEART_RATE` แทน `BODY_SENSORS` (manifest จบที่ `maxSdkVersion="35"`)
- 🔴 ก้าวต้อง `aggregate` ห้ามบวกเอง · นาฬิกากับแอปออกกำลังกายเขียนซ้ำกันได้ Health Connect ตัดซ้ำให้เฉพาะทางนี้
- Health Connect ให้อ่านตอนแอปอยู่บนจอ · ไม่ขอ `READ_HEALTH_DATA_IN_BACKGROUND` โดยตั้งใจ · อยู่หลังบ้านได้สถานะ `background` เธอบอกให้เปิดแอป
- ไม่ได้ค่าเซ็นเซอร์ภายในสองวินาที (ชีพจรสิบสองวินาที) = `no_reading` ไม่ใช่ศูนย์ · Android ไม่ส่งค่าให้แอปหลังบ้านและไม่แจ้ง error
- ยังไม่ได้ลองบนเครื่องจริง · ค่าจาก Health Connect บนเครื่องเจ้าของขึ้นกับว่ามีแอปเขียนข้อมูลเข้าไปไหม

## เครื่องล็อกอยู่

เสียง ไฟฉาย เพลง โหมดสั่น สั่งได้ (ย้อนกลับได้ทันที ไม่เปิดเผยอะไร ขับรถอยู่ต้องสั่งได้) ·
เซ็นเซอร์รอบตัวอ่านได้ (ไม่บอกเรื่องตัวเจ้าของ) ·
รายการโปรเซส ตารางแอป และการแก้ตาราง ต้องปลดล็อกก่อน (`_voiceBarred`) · สุขภาพ ก้าว และชีพจรต้องปลดล็อกก่อนทุกทาง (`_healthBarred`) ·
คำเรียกไม่ใช่การยืนยันตัวตน
