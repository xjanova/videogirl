# มายด์คุมเครื่อง — ทำอะไรได้แค่ไหน (ตรวจ 2026-11-02)

| จัดไอคอนหน้าจอ | มือ ขั้น `drag` | ยังไม่ได้ลองกับตัวเปิดแอปของ vivo |

## โปรเซส

Android ปิด `/proc` และ `getRunningAppProcesses` ให้แอปเห็นแค่ตัวเอง · ทางเดียวคือ `ps -A` ในฐานะ shell ผ่าน
`DirectAudioServer` (argv ตายตัว ไม่ผ่าน shell ไม่รับอาร์กิวเมนต์ · ชื่อโปรเซสตัดเหลือ ASCII พิมพ์ได้ · เฟรมเดียว)

- 🔴 `AudioProtocol.VERSION` ห้ามขยับ · ตัวช่วยรุ่นเก่าจะปฏิเสธการเชื่อมต่อแล้วเสียงสายพังทั้งชุด · คำสั่งใหม่ที่รุ่นเก่าไม่รู้จักตอบ `error:` เฉย ๆ (`old_helper`)
- 🔴 หลังลงแอปรุ่นนี้ ตัวช่วยที่รันอยู่ยังเป็นตัวเก่า ต้องเชื่อมใหม่หนึ่งครั้งที่ ตั้งค่า › รับสาย
- ระหว่างสายใช้ไม่ได้: ตัวช่วยมีได้เซสชันเดียว และเซสชันนั้นคือสาย (`in_call`)
- ดูอย่างเดียว ไม่มีคำสั่งปิดโปรเซส (ทำลายงานเจ้าของได้ และไม่มีใครขอ)
- ห้ามสลับ Wireless debugging เพื่ออ่านรายการนี้ · บาง ROM ฆ่าตัวช่วย

## ตารางแอป (`lib/hands/app_table.dart` · ตาราง `apps` รุ่นฐาน 4)

- แอปหลังบ้านรับข่าวติดตั้ง/ถอนไม่ได้ · เทียบรายการในเครื่องตอนเปิดแอป กลับเข้าแอป ทุกสิบนาทีระหว่างคุย และตอนเปิดแอปไม่เจอ
- 🔴 รายการว่างหรืออ่านไม่ได้ = ไม่เปลี่ยนอะไร · ไม่กันคือถอดทุกแอป หมวดและชื่อเรียกหายทั้งตาราง
- ตารางเปล่าครั้งแรกไม่นับเป็นข่าว · ถอดแล้วลงใหม่ หมวดและชื่อเรียกยังอยู่ · หมวดที่ตั้งเอง (`own_category`) การเดาใหม่ทับไม่ได้
- `find`: ตรงเป๊ะ > ขึ้นต้น > มีคำนั้น · เท่ากันทุกแถว = null ให้ตัวหาฝั่ง Android ตอบพร้อมตัวเลือก แทนการเปิดผิดแอป
- 🔴 ชื่อแอปคือข้อความจากคนอื่น · ทุกทางเข้าโมเดลผ่าน `_one` ไม่ให้เหลือรูป `[[…]]`
- ข่าวใน prompt ไม่มีคำบอกเวลาสัมพัทธ์ · prompt ที่เปลี่ยนทุกตาบังคับสมองในเครื่องเริ่ม session ใหม่

## จัดไอคอน

Android ไม่มี API ให้แอปอื่นย้ายไอคอนของตัวเปิดแอป · ทางเดียวคือนิ้วจำลอง: กดค้าง 750 ms แล้วลากต่อด้วย `continueStroke`
ทั้งเส้นเป็นนิ้วเดียว · ค้างปลายทาง 450 ms (ขอบจอ 1200 ms ให้พลิกหน้า) · ลงบนไอคอนอื่น = ทำโฟลเดอร์

- ตารางแอปไม่ได้ย้ายไอคอน · ตารางคือความรู้ของเธอ การย้ายจริงคือ `phone_task`
- `PhonePolicy`: ลงบนปุ่มที่มีคำเสี่ยง (ถอนการติดตั้ง ลบ) ต้องถามเจ้าของ · ตัวติดตั้งแอปเป็นด่านระบบที่มือแตะไม่ได้อยู่แล้ว
- งานหนึ่งมีสูงสุด 30 ขั้น จึงแบ่งเป็นรอบ

## เครื่องล็อกอยู่

เสียง ไฟฉาย เพลง โหมดสั่น สั่งได้ (ย้อนกลับได้ทันที ไม่เปิดเผยอะไร ขับรถอยู่ต้องสั่งได้) ·
รายการโปรเซส ตารางแอป และการแก้ตาราง ต้องปลดล็อกก่อน (`_voiceBarred`) · คำเรียกไม่ใช่การยืนยันตัวตน

## ยังไม่มี

เซ็นเซอร์ (`SensorManager`) · สุขภาพ (Health Connect · `BODY_SENSORS` · `ACTIVITY_RECOGNITION`) · ตำแหน่ง ·
สูงสุดที่ไม่ root คือ uid shell (2000) ไม่ใช่ root
